Destructuring & Spread

The syntax every modern codebase assumes you read fluently.

1 · Readthe concept
2 · Watchthe animation
3 · Practiceget checked
4 · Provesay it out loud
In plain words Destructuring is unpacking a box straight onto labeled shelves: instead of carrying the whole object around, you pull out exactly the pieces you need, each into its own named variable. Spread (...) is the opposite move: taking something packed and pouring its contents out — into a new array, a new object, or a function call.

1.Read the concept

Object destructuring — pull out what you need, by name

const user = { name: "Sam", age: 30, city: "Berlin", role: "dev" };

const { name, age } = user;              // name="Sam", age="30" — city/role ignored
const { name: userName } = user;         // RENAME: the variable is called userName
const { phone = "none" } = user;         // DEFAULT: used only when the key is missing
const { name: n, ...rest } = user;       // REST: everything else gathered into an object

It composes — nested paths, and (critically) function parameters. You'll see this signature in every modern codebase:

function sendEmail({ to, subject, cc = [] }) {   // options object destructured
  console.log(to, subject, cc.length);
}
sendEmail({ to: "a@b.com", subject: "Hi" });     // cc defaults to []

Array destructuring — pull out by position

const rgb = ["#ff", "#00", "#33"];

const [red, green, blue] = rgb;      // by position
const [first, , third] = [1, 2, 3];  // skip holes: first=1, third=3
const [head, ...tail] = [1, 2, 3];   // head=1, tail=[2, 3]
const [x = 0, y = 0] = [5];          // x=5, y=0 (default kicked in)

let a = 1, b = 2;
[a, b] = [b, a];                     // the famous swap — no temp variable

Spread — expand, copy, merge

// arrays
const copy  = [...arr];              // shallow copy
const merged = [...arr1, ...arr2];
const withNew = [...arr, newItem];   // the immutable-update idiom

// objects
const patched = { ...user, age: 31 };        // copy + override — order matters!
const both   = { ...defaults, ...options };  // options wins on conflicts

// function calls
Math.max(...nums);                            // elements become arguments
The one trap: spread copies are SHALLOW { ...user } copies the top level only. A nested address object is still shared with the original — mutating the copy's address mutates the original's too. Deep copies need structuredClone() or a library. "Is spread deep or shallow?" is a standing interview question with real bug consequences.

Exceptions & traps — the complete list

  • Defaults apply only to undefined — { port = 3000 } = { port: null } leaves port as null; an explicit null overrides the default.
  • Destructuring undefined throws — const { a } = undefined crashes; guard with = {} defaults: const { a } = maybeUndefined || {} or function f({ a } = {}).
  • Renaming means the original name doesn't exist — const { name: n } = obj creates only n.
  • Rest must be last — const { ...rest, a } = obj is a SyntaxError.
  • Spread copies are shallow — nested objects are shared; deep copies need structuredClone.
  • Spread order decides the winner — { ...defaults, ...options }: options win. Reversed, defaults silently stomp user choices.
  • Array holes vs undefined: const [a, b] = [1] gives b = undefined (no error) — shapes don't have to match.
  • Swap works only with let — [a, b] = [b, a] needs reassignment; consts can't participate.

4.Prove it

Your interview answer — rehearse out loud, recorded, no notes "Destructuring unpacks values into variables: objects by key — with renaming, defaults, and rest for the leftovers — and arrays by position, including the skip-hole pattern and the classic swap. It shines in function signatures, where an options object gets destructured straight into named parameters with defaults. Spread expands an iterable into elements: copying arrays, merging objects where later spread wins conflicts, and immutable updates like adding an item without mutating. One caution I always mention: spread copies are shallow — nested objects are still shared with the original — so deep changes need structuredClone."

Both sides of the dots: unpack (destructuring) and expand (spread), plus the shallow-copy caveat. Complete.
